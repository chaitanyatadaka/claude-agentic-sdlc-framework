# Framework documentation

This folder will hold the framework's documentation for its users and maintainers:

- Architecture and workflow
- Agent responsibilities and boundaries
- Orchestrator design
- Approval process
- Iteration and retry strategy
- Permissions and security model
- Installation and configuration
- Usage
- Troubleshooting

Written so far:

- `agents.md`: the eight agents, their tools, boundaries, and shared skills.
- `orchestrator.md`: the `/sdlc` command, the script commands, checkpoints, policy bounds, and known limits.

These documents are written and maintained by framework developers. Agents do not edit them during a story run.

The verification report from the design phase will also be stored here when it is finalized.
